# Connecting Windsurf

The MCP server URL is `https://mcp.carbonvoice.app`.

1. Open **Windsurf Settings**.
2. Under **MCP Servers**, click **Open MCP Marketplace**.
3. Click the **gear** in the top right.
4. Add a `carbonvoice` entry to the MCP servers JSON, using the `http` transport and
   the URL above.
