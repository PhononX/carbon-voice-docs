# Apple Watch app

Capture thoughts wherever inspiration strikes. With the Apple Watch app you can:

- Record memos with a single tap using the Carbon Voice complication.
- Record even when offline.
- Sync automatically with the mobile app.

Make sure you're on the latest version to use it.
