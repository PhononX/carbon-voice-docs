# Personalize the voice for messages you type

When you type a message, Carbon Voice generates audio so the recipient can listen to it
rather than read it. You can personalize how that sounds:

- Set the text-to-speech gender.
- Choose the premium TTS engine, which sounds better.
- Clone your voice, so typed messages sound like you said them.

![Text to speech settings](/img/account-and-settings/text-to-speech-settings.webp)

## Changing the setting

1. Tap your profile menu — your profile picture at the bottom right.
2. Select **Global Voice**.
3. Under **Text-to-Speech**, choose how your typed messages should sound.

Your preference applies to new messages you send after making the change.

## Things to know

- These settings apply both when you type a message and when a message of yours is
  translated into another language.
- TTS gender is used with the basic or premium engine — and also with cloning, when
  translating into a language where cloning isn't supported.
