# Integrations

Carbon Voice conversations include people and agents alike, which means the tools you
already use can listen to and take part in what your team is discussing.

## Agents in conversations

An AI agent can be a participant in a [conversation](../conversations/index.md) in the
same way a person is: it hears what was said and can contribute.
