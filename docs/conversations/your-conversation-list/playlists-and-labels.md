# Playlists and labels

Label messages to manage follow-up and find them again later. Putting a label on a
message can add it to a playlist, which shows at the top of your home screen — or you
can label a message simply to find it in Notebook.

## Add a label

Press and hold on a message, select **Labels**, then choose the labels you want to
apply.

![Labels](/img/conversations/labels.webp)

## Manage labels and playlists

To control which labels create playlists, or to add new ones, go to **Notebook →
Labels → 3-dot menu → Manage Labels**.
