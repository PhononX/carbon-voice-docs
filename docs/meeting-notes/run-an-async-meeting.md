# Run an async meeting

An **async meeting** is a conversation with a deadline. You set a topic and a time by which
you'd like replies, everyone contributes when it suits them, and the discussion closes
itself when the time is up.

## Create one

1. Tap the **"+"** on Home and choose **Async Meeting**. On desktop, press **⌘N**. From
   Slack, type `/cv meeting` — see [Slack](../integrations/slack.md).
2. **Name the meeting** and choose the workspace it belongs to.
3. **Add people** — by name, email address, or phone number.
4. **Set the reply deadline.** Choose from **Urgent**, **Later today**, **Tomorrow
   morning**, **Tomorrow night**, **In a few days**, or set your own end date and time.
5. Create it.

## Record a kick-off

The first message sets up the discussion. Say what you want people to weigh in on, and
what a useful answer looks like. Tap **Record Kick-off** to record it.

A good kick-off is a specific question. "Thoughts on the roadmap?" gets you silence;
"Which of these three things should we cut, and why?" gets you a decision.

## While it's running

- **The countdown** shows how long is left, and everyone sees it on the conversation.
- **Reminders** nudge people who haven't contributed yet, so you don't have to chase.
- **Engagement stats** show who has caught up and who hasn't — tap the engagement button in
  the conversation to see the breakdown.
- **Extend it** if the discussion needs longer. Only the meeting's owner can, so ask them
  if you're not.

## When it ends

The meeting closes and you get the write-up: the transcript, the summary, and any action
items AI found. See [Get the notes](get-the-notes.md).

Messages stay in the conversation afterwards, unless your workspace has a retention policy
that clears them after a set number of days. See
[Advanced workspace settings](../workspaces/advanced-settings.md).

## Joining one

Historical messages appear as **unheard and unread** when you join an async meeting, so
the whole discussion so far is queued up for you, rather than quietly marked as seen. This
is different from joining an ordinary conversation, where earlier messages appear unheard
but already read.
