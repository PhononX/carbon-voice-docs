# Easy Voice Agents

Easy Voice Agents are agents Carbon Voice provides, for talking to popular tools by voice —
entering information or asking questions without opening the tool itself.

They're the shortcut past [creating and connecting](create-an-agent.md) an agent of your
own. You don't build anything; you pick one and start talking.

## Using one

1. Open **AI Agents**. Easy Voice Agents sit above your own Personal Agents.
2. Tap the one you want.
3. Choose the **workspace** the conversation should live in.
4. Tap **Start Conversation**.

The conversation opens with a setup message already sent, asking the agent to show you how
to set it up — so your first exchange is the agent walking you through its own
configuration.

## Coming back

Any conversations you already have with an agent are listed under **Active Conversations**
on its page. Tap one to pick up where you left off.

> Easy Voice Agents are rolled out gradually, so the list depends on your account. If an
> agent shows as unavailable, it isn't ready for your account yet.
