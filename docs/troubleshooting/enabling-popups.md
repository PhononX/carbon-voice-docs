# Enabling pop-ups so you can log in on the web

Logging in on the web requires pop-ups to be enabled.

**On desktop**, tap the pop-up icon in the URL bar and allow pop-ups for the site.
Safari's own instructions are
[here](https://support.apple.com/guide/safari/block-pop-ups-sfri40696/17.0/mac/14.0).

**On iOS**, go to **Settings → Safari** and turn off **Block Pop-ups**.
