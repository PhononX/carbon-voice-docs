# Playback speed

You can speed up playback on messages up to 4x.

While a message is playing you'll see the current speed:

- Tap the **+** to the right of the speed to go faster.
- Tap the **−** to the left of the speed to slow down.
- Tap the **5 with the rounded arrow** to jump back five seconds.
