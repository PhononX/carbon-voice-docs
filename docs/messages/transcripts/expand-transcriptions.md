# One-tap to expand transcriptions

Messages can be long. Rather than tapping **show more** on each one, you can expand
every transcript in a conversation at once.

- **Expand everything.** Tap the expanding arrows icon at the top of the conversation
  to reveal the full transcription of every message card.
- **Collapse it again.** The same icon collapses all transcriptions back to their
  compressed state, so you control how much text is on screen.

This is most useful for lengthier discussions when you would rather read than listen.
