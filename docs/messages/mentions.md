# Tagging people and agents

Tagging pulls a particular person or agent into a message.

## Tagging someone

Press and hold a message and choose **Tag people**, then pick who you mean.

A tagged person gets **an extra push notification and an inbox notification**, on top of
whatever they'd normally receive for the conversation. So a tag is how you get attention
in a busy conversation without messaging everyone separately.

## Tagging an agent

Agents can be tagged the same way. It's worth knowing that **some agents need to be tagged
in a group conversation before they'll engage at all**. In a conversation with several
people, an agent may wait to be addressed rather than responding to everything.

If an agent isn't answering in a group conversation, tag it.

## Finding your tags

Everything you've been tagged in is collected under **Mentions**, in your
[notification inbox](../account-and-settings/inbox.md) and in Notebook.
