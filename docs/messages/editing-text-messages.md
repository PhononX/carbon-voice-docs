# Editing text messages

A text message you've already sent can be edited.

1. Press and hold the sent message.
2. Tap **Edit Text Message**.
3. Make the change and tap **Done**.

The edit updates **both the text and the audio**. Because a typed message is read aloud
for whoever listens rather than read on screen, the spoken version is regenerated to match
what you changed, so someone who plays it after your edit hears the corrected version, not
the original.
