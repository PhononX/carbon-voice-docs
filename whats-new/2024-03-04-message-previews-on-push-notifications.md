# Message previews on push notifications

You can now see what a message is about without opening the app — so you get the gist
right away, and stop guessing which notification to check first.

<!-- truncate -->

Every push notification now carries a short preview of the message, along with:

- ✍️ whether it's a **text message**
- 🎙️ whether it's a **voice message**
- ✨ an **AI summary**, for longer messages
