# Web attachments and performance improvements

Two clear top requests came out of our recent survey: file attachments on web, and better
performance on web and mobile. This release is mostly those two.

<!-- truncate -->

## Web attachments

The web app now supports file attachments. You can attach and send images, videos, and files
like a PDF, and download them from the web app too.

## Mobile performance

The app should feel lighter overall, for two reasons.

**The interface is more grouped.** Related and relevant actions now sit together, which makes
them faster to find — you'll notice it most during playback and recording.

**It's faster.** We sped up key actions under the hood, especially once your contacts or
conversations have grown a lot, and improved a number of places where a weak network
connection caused slowness. More is on the way.

If you spot anything slow or buggy, tell us through **Help → Support**.

## Also in this release

- **Starting new messages.** Existing conversations now appear in the **+** in the lower
  right, making it the fastest way to send a message to a person or an existing conversation.
- **Personal notes.** Listening to a message and want to remember several things to say? Take
  private notes in the message details, and you'll see them in the conversation when you
  reply.
- **Apple Watch.** There's an
  [updated video](https://youtube.com/shorts/urx2uBXdyLI) on capturing ideas from your wrist.
